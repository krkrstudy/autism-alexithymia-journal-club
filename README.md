# 孤独症中的述情障碍：中文交互式文献分享

面向心理学或认知神经科学实验室组会的 22 页中文网页演示，围绕以下问题组织证据：

> 孤独症个体中观察到的情绪识别、表达、共情与调节困难，在多大程度上来自孤独症本身，又在多大程度上可由共现的述情障碍解释？

## 在线浏览

启用 GitHub Pages 后可访问：

<https://krkrstudy.github.io/autism-alexithymia-journal-club/>

## 内容

- 22 页连续证据链，而非逐篇文献摘要；
- 元分析、纵向研究、共情与内感受、两项 fMRI、双生子遗传和临床样本；
- 研究结果、作者解释与综合推论分开标注；
- 8 篇核心论文的文献卡片；
- 每页中文讲稿；
- 综合理论模型、方法学批判、研究与临床启示；
- APA 第 7 版核心参考文献与原文链接。

## 使用

- `← / →`、`↑ / ↓`、空格或 Page Up / Page Down：翻页；
- `N`：显示或隐藏当前页讲稿；
- `P`：打印或导出 PDF；
- 右上角“文献卡片”：打开研究问题、方法、结果、局限与过渡语。

## 说明

所有样本量、关键效应量、置信区间和回归系数均按论文原文核对。TAS 临界值代表量表筛查分类，不等同于独立临床诊断。内容更新至 2026 年 6 月。
