# 孤独症与述情障碍：深度中文科普专题

一份面向普通读者、心理学学生与认知神经科学研究者的长篇中文科普网站，系统解释孤独症、述情障碍、内感受、共情、情绪加工与心理健康之间的关系。

## 在线阅读

<https://krkrstudy.github.io/autism-alexithymia-journal-club/>

## 网站内容

- 三分钟核心结论与关键数据；
- 述情障碍 DIF、DDF、EOT 三个维度的通俗解释；
- TAS-20、PAQ 与测量等值问题；
- 共现比例及其正确解读；
- 发展路径、共同病因与发展性相互作用模型；
- 纵向、共情与内感受、脑成像、双生子遗传和临床证据的详细拆解；
- 每项核心研究的样本、设计、关键结果、作者解释与局限；
- 可交互的证据筛选与因果角色小课堂；
- 研究和临床意义、未来研究空白、FAQ 与术语表；
- APA 第 7 版核心参考文献和原文链接。

## 使用说明

- 点击正文虚线术语或右上角“术语表”查看概念解释；
- 在证据链章节按研究类型筛选文献；
- 在因果推断章节切换述情障碍的不同因果角色；
- 点击“大字”切换阅读字号；
- 页面支持移动端和打印。

所有样本量、关键效应量、置信区间与回归系数均按论文原文核对。网站用于科研科普和组会学习，不替代个体化临床评估或诊断。内容更新至 2026 年 6 月。
